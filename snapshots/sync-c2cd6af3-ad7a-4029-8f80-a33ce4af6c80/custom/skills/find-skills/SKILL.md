# Find Skills

在猜测之前，先检查本地已安装的技能。将用户的请求与已安装技能的**名称**和**描述**进行匹配，然后报告最佳匹配项，或者声明未找到匹配的已安装技能。

## 工作流程

1.  首先读取可用的技能列表。
2.  如果用户提供了主题或能力要求，则搜索匹配的名称和描述。
3.  如果有一个技能明显相关，则推荐或加载该技能。
4.  如果有多个技能都 plausible，则提供一个简短列表，并为每个技能附上一行的匹配理由。
5.  如果没有技能匹配，直接说明，不要虚构技能。

## 如何检查

*   检查 `~/.claude/skills/*/SKILL.md` 下的已安装技能元数据。
*   将用户的措辞与 `name` 和 `description` 字段进行比较。
*   优先选择**精确的领域匹配**，而非泛泛的重叠。
*   除非技能确实存在，否则不要声称某个技能已安装。

## 输出风格

*   保持结果简洁。
*   包含技能名称和一行的匹配理由。
*   如果没有匹配项，输出：`No installed skill matched this request.`

## 示例

*   `安装了哪些技能？`
*   `查找用于处理 PDF 文件的技能。`
*   `有创建 PowerPoint 幻灯片的技能吗？`
*   `哪个已安装的技能最匹配这个任务？`
