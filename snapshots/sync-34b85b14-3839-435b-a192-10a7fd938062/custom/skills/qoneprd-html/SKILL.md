# QonePRD Html：交互式HTML产品原型生成

这是 `prototype-html` 的独立开发副本。它保留原 skill 的单文件 HTML、右侧说明、SVG 连线和悬停高亮能力，并将布局改造成接近 Axure RP 的原尺寸无限画布；后续改造只在本目录进行，不修改原 `prototype-html`。

根据产品需求，生成完整的、可直接运行的单文件HTML产品原型。

## 核心工作流程

1. **理解需求** - 明确用户需要展示的产品功能和界面元素
2. **设计布局** - 规划左侧界面元素与右侧说明文档的对应关系
3. **编写代码** - 生成符合所有技术规范的完整HTML文件
4. **验证检查** - 确保所有连线正确、交互完整、响应式正常

## 布局规范（严格执行）

### 原尺寸无限画布

- 使用“单一滚动视口 + 内部无限画布”的结构，不使用 80%/20% 的百分比分栏作为默认布局。
- 原型页面必须保持用户指定的原始宽高；未指定时默认使用 1440px × 900px。
- 页面内容放在 `#prototype-page`，说明内容放在页面右侧的 `#notes-board`，说明区不计入原型页面宽度。
- 说明区宽度必须内容驱动，不得固定为 360px 或其他单一宽度；允许根据说明卡片、Tab 和文本内容自然扩展到所需宽度。
- 空的流程说明和测试用例 Tab 可保留一个最小可用宽度，防止面板塌缩，但不得设置固定最大宽度。
- `#workspace-viewport` 负责水平和垂直滚动；页面、说明和连线必须位于同一个 `#workspace-canvas` 坐标系内。
- 页面不能因浏览器变窄而压缩；需要通过滚动条访问完整页面和右侧说明。
- 画布尺寸必须根据页面高度、说明高度、页面宽度、说明实际渲染宽度和间距自动计算。

推荐结构：

```html
<main id="workspace-viewport">
  <div id="workspace-canvas">
    <section id="prototype-page" data-page-width="1440" data-page-height="900"></section>
    <aside id="notes-board"></aside>
    <svg id="connections"></svg>
  </div>
</main>
```

页面和说明之间默认保留 160px 空白间距；可根据内容调整，但不得通过缩小页面来消除间距。

### 连线功能（必须严格执行）

使用 SVG 技术绘制连线，确保连线清晰可见且不遮挡内容。SVG 必须放在 `#workspace-canvas` 内，而不是放在浏览器视口层。

**连线规则：**
- 选择左侧界面中2-4个重要元素增加连线指向右侧对应的功能说明
- 连线的**起始点**必须精确连接到左侧元素的右侧边缘中点
- 连线的**结束点**必须精确连接到右侧对应说明文字的左侧边缘中点
- 连线采用平滑的贝塞尔曲线，避免生硬的直角转弯
- 连线线条粗细为 2px
- 连线坐标相对于 `#workspace-canvas` 计算，不相对于 `window` 或独立面板计算
- 普通画布滚动不需要重算连线；页面尺寸、说明展开、窗口尺寸变化时再重算

**交互效果：**
- 当鼠标悬停在左侧元素上时，对应的连线加粗并高亮显示
- 当鼠标悬停在右侧说明文字上时，对应的连线和左侧元素也会高亮显示

**连线标注：**
- 每条连线旁边添加小的数字编号，与右侧说明的编号对应

**连线开关：**
- 提供“连线”开关，默认开启时显示贝塞尔连线和连线中部编号。
- 关闭连线时隐藏所有路径，改为在每个连线开始端显示对应的圆形序号标记（1、2、3……）。
- 开始端序号必须与右侧说明的 `data-proto-id` 一致，且位于起始元素右侧边缘中点附近。
- 关闭连线后，序号标记仍支持悬停高亮，并能高亮对应页面元素和说明卡片。

## 说明区 Tab

- 右侧说明区提供三个 Tab：`功能说明`、`流程说明`、`测试用例`。
- 默认激活 `功能说明`，用于承载带 `data-proto-id` 的连线说明卡片。
- `流程说明` 和 `测试用例` 默认保留空面板，后续按项目需求填写。
- 切换到非 `功能说明` Tab 时，隐藏功能连线和开始端序号，避免说明内容切换后产生错误映射；切回 `功能说明` 时恢复连线状态。

## 响应式设计规范

### 默认模式：原尺寸画布

- PC 端和手机端都保持原型页面的设计宽度。
- 小屏幕通过水平滚动访问完整页面，不强制把页面改成上下布局。
- 说明区继续位于页面右侧，连线默认保留。

### 可选模式：适配视图

- 可以提供“适配视图”按钮，将页面缩放到当前视口用于演示。
- 适配视图可以隐藏说明和连线，但不能修改页面的原始宽高。
- “原尺寸画布”和“适配视图”是显示模式切换，不是两套页面结构。

## 技术栈要求

1. **纯前端实现**：使用纯HTML、CSS和原生JavaScript，不依赖任何外部框架
2. **样式**：使用Tailwind CSS v3，通过CDN引入
3. **图标**：使用Font Awesome图标库，通过CDN引入
4. **代码结构**：
   - HTML结构语义化，使用适当的标签
   - CSS样式内联在`<style>`标签中
   - JavaScript代码内联在`<script>`标签中
   - 所有代码整合在一个HTML文件中，无需外部资源

## 样式与视觉规范

### 配色方案
- 如果用户指定了色系则用用户指定的色系，否则用下面默认的色系
- **主色调**：蓝色 `#165DFF`
- **辅助色**：浅灰色 `#F5F7FA`、深灰色 `#333333`
- **强调色**：绿色 `#00B42A`（成功状态）、红色 `#F53F3F`（错误状态）

### 其他样式要求
- 右侧的功能说明区要用琥珀色系，跟左侧内容区区分开！
- **字体**：系统默认无衬线字体
- **间距**：以 8px 为基本单位，保持一致的间距系统
- **阴影**：适当使用轻微阴影增强层次感
- **整体风格**：简洁、现代、专业的产品原型风格

## 输出要求

1. 输出完整的HTML文件代码
2. 代码开头添加简短说明，介绍原型的功能和使用方法
3. 确保页面保持原始设计宽度，并且画布出现正确的横向、纵向滚动条
4. 确保所有连线的起始和指向位置完全正确，滚动后仍与目标元素保持相对位置
5. 确保关闭连线后每个开始端仍显示与说明对应的序号标记
6. 确保说明区三个 Tab 可以切换，流程说明和测试用例默认为空
7. 确保原尺寸画布和适配视图在不同屏幕尺寸下都能正常显示和交互

## 注意事项

- 连线计算必须在 DOM 渲染完成后执行，使用 `DOMContentLoaded`、`resize` 和 `ResizeObserver` 重新计算
- 页面、说明和 SVG 必须共享同一个滚动画布；不要给页面和说明分别设置独立的垂直滚动容器
- 确保SVG的 `pointer-events-none` 不会阻挡下方元素的交互
- 适配视图切换时，需要平滑过渡动画，但不能破坏原尺寸页面
- 连线关闭状态不能删除说明映射；必须保留开始端序号标记
- 流程说明、测试用例 Tab 默认不填充业务内容，避免虚构需求或测试结论
- 所有元素ID和数据属性命名要清晰，便于连线脚本定位
- 不要让连接目标使用 `position: sticky`；如果确实需要 sticky，必须在滚动时额外重绘连线
